# 视觉语言

| 机制 | 机械对象 | 动作含义 |
| --- | --- | --- |
| 等待执行 | 带挡板的工单料仓 | 出仓表示选中任务 |
| 调度、判断 | 有拨盘的控制台 | 指示灯表示当前步骤 |
| 模型处理 | 带散热片的计算机芯 | 芯片亮起表示处理活动 |
| 短期/长期记忆 | 可分层打开的转盘柜 | 读取/写入是不同步骤 |
| 工具调用 | 有滑轨和夹具的机械臂 | 工具执行时点亮夹具 |
| 请求路由 | 接线交换台 | 已证实的关系接入实际端口 |
| 持久化 | 圆柱存储柜 | 记录落盘是独立操作 |
| 语音输入/输出 | 采音探头 / 扬声器 | 采集与播报不可混为一项 |

保持一套投影。用上、左、右三个面表达体积；用螺钉、插槽、支脚、散热片表达功能。细节必须附着在部件上。连线终点必须连接端口。

默认使用暖白纸面、灰色金属、蓝绿控制、赭色数据和红色错误。避免渐变背景、荧光装饰、大块空白标题和纯装饰齿轮。页面的说明与机器放在同一屏；手机允许图形缩放，详情置于图形下方。

“3B1B”取教学方式：一次突出一项机制、清楚显示变化前后、把原因和结果放在一起。不要承诺复刻其品牌、字体或动画。

原始启发：[Anatomy](https://github.com/wheresryan22/anatomy)，读取日期 2026-10-12。原版用真实机械对象解释概念，提供 SVG、可选 WebGL 和 3D。本技能的代码和模板独立编写；v1 仅实现 SVG 2.5D，不包含原版的 WebGL、3D 几何审计或性能保证。
